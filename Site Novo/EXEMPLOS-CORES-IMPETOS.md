O cinza indica uma vaga sem preenchimento, não uma sexta categoria de ímpeto aplicado. Uma build publicada pode preencher a vaga: nesse caso ela usa a cor do ímpeto escolhido, e não fica cinza.

Atualização visual aplicada em 06/09/2026: cores-base confirmadas nas texturas `CmnIconBooster`, conforme `4-DOCUMENTOS/MANUAL-DAS-TABELAS.md`. Cinza físico `#4C4C4C`; texto da vaga permanece mais claro para leitura. Fundos e bordas usam transparências sobre essas cores-base. Os tokens antigos da API foram preservados (`amarelo` representa âmbar/raw2; `dourado`, amarelo/raw5).

A classificação de cor não garante por si só que exista uma build publicada para o card. O site continua mostrando somente a publicação real; não calcula nem inventa conteúdo para exemplificar uma cor.
