# Recuperar a versão anterior do extrator

1. Feche a página e encerre a janela do executor local.
2. Não apague a pasta da versão nova nem seus manifestos.
3. Localize `VERSOES-ANTERIORES\2026-08-26\Extrator-ClubEfootball.html`.
4. Confira o SHA-256 esperado: `5102D165952C9B29050D105B4D31DE5DE1073540811D371C2562ED8BFC0805F5`.
5. Abra essa cópia diretamente para consulta ou copie-a para um nome diferente.
6. Não use o comportamento automático do legado para promover uma base sem revisão; ele foi preservado para recuperação e comparação, não como fluxo recomendado.

Para recuperar dados depois de uma aplicação futura, use o manifesto de aplicação e gere um diff inverso revisável. Nenhuma exclusão ou restauração deve ser automática.
